Model serving is one of the most common GPU workloads. With Shadeform you can deploy a model onto the most affordable GPU on the market with a single API call, using the `docker` [launch configuration](/getting-started/concepts#launch-configuration) to start [vLLM](https://docs.vllm.ai/) as soon as the instance is active.

In this guide we deploy [Mistral-7B-Instruct-v0.2](https://huggingface.co/mistralai/Mistral-7B-Instruct-v0.2) behind vLLM's OpenAI-compatible server on an A6000.

<Prerequisites />

This guide builds on [finding the best GPU](/guides/mostaffordablegpus) and [running Docker containers](/guides/dockercontainers).

### Find an available A6000

List A6000 instance types that are available right now, sorted by price, and pick the cheapest `cloud` / `region` pair from the response.

<CodeGroup>
  ```bash curl
  curl --request GET \
  --url 'https://api.shadeform.ai/v1/instances/types?shade_instance_type=A6000&available=true&sort=price' \
  --header 'X-API-KEY: <api-key>'
  ```

  ```bash CLI
  shade instances list-types --shade-instance-type A6000 --available --sort price
  ```
</CodeGroup>

### Launch vLLM

Create the instance with a `docker` launch configuration. The `vllm/vllm-openai` image takes the model as an argument and listens on port 8000. Because containers run with `--network=host`, port 8000 on the VM reaches vLLM directly.

<Note>
  Mistral's Hugging Face repos are gated. Accept the license on Hugging Face and pass a read token as `HUGGING_FACE_HUB_TOKEN`. Ungated models such as `HuggingFaceH4/zephyr-7b-beta` do not need the token.
</Note>

<CodeGroup>
  ```bash curl
  curl --request POST \
  --url 'https://api.shadeform.ai/v1/instances/create' \
  --header 'X-API-KEY: <api-key>' \
  --header 'Content-Type: application/json' \
  --data '{
    "cloud": "massedcompute",
    "region": "us-central-2",
    "shade_instance_type": "A6000",
    "shade_cloud": true,
    "name": "vllm-mistral",
    "launch_configuration": {
      "type": "docker",
      "docker_configuration": {
        "image": "vllm/vllm-openai:latest",
        "args": "--model mistralai/Mistral-7B-Instruct-v0.2",
        "envs": [
          {
            "name": "HUGGING_FACE_HUB_TOKEN",
            "value": "<hugging-face-token>"
          }
        ]
      }
    }
  }'
  ```

  ```bash CLI
  shade instances create \
    --cloud massedcompute \
    --region us-central-2 \
    --shade-instance-type A6000 \
    --shade-cloud=true \
    --name vllm-mistral \
    --launch-configuration '{
      "type": "docker",
      "docker_configuration": {
        "image": "vllm/vllm-openai:latest",
        "args": "--model mistralai/Mistral-7B-Instruct-v0.2",
        "envs": [
          { "name": "HUGGING_FACE_HUB_TOKEN", "value": "<hugging-face-token>" }
        ]
      }
    }'
  ```
</CodeGroup>

```json Response
{
  "id": "d290f1ee-6c54-4b01-90e6-d701748f0851"
}
```

Shadeform provisions the VM, pulls the image and starts the container. Expect 5-10 minutes end to end depending on the cloud and the size of the model weights. See the [Create Instance API Reference](/api-reference/instances/instances-create) for every field.

### Wait for the instance

Poll the instance until `status` is `active` and take note of the `ip`.

<CodeGroup>
  ```bash curl
  curl --request GET \
  --url 'https://api.shadeform.ai/v1/instances/<instance-id>/info' \
  --header 'X-API-KEY: <api-key>'
  ```

  ```bash CLI
  shade instances get <instance-id>
  ```
</CodeGroup>

<Note>
  `status` describes the VM, not the container. After the VM is `active`, vLLM still needs to download the model and load it onto the GPU, which takes a few more minutes.
</Note>

You can watch the container start from the **Logs** tab of the instance under [Running Instances](https://platform.shadeform.ai/instances), or SSH in and follow it directly:

```bash
ssh -i <path-to-private-key> shadeform@<instance-ip>
docker container ls
docker container logs -f <container-id>
```

vLLM is ready once the log shows the server listening:

### Query the model

vLLM exposes the OpenAI API. List the loaded model, then send a completion.

<CodeGroup>
  ```bash curl
  curl http://<instance-ip>:8000/v1/models

  curl --request POST \
  --url 'http://<instance-ip>:8000/v1/chat/completions' \
  --header 'Content-Type: application/json' \
  --data '{
    "model": "mistralai/Mistral-7B-Instruct-v0.2",
    "messages": [
      {"role": "user", "content": "San Francisco is a"}
    ],
    "max_tokens": 32
  }'
  ```

  ```python openai
  from openai import OpenAI

  client = OpenAI(api_key="EMPTY", base_url="http://<instance-ip>:8000/v1")

  completion = client.chat.completions.create(
      model="mistralai/Mistral-7B-Instruct-v0.2",
      messages=[{"role": "user", "content": "San Francisco is a"}],
      max_tokens=32,
  )
  print(completion.choices[0].message.content)
  ```
</CodeGroup>

### Clean up

Delete the instance when you are done so you stop being billed.

<CodeGroup>
  ```bash curl
  curl --request POST \
  --url 'https://api.shadeform.ai/v1/instances/<instance-id>/delete' \
  --header 'X-API-KEY: <api-key>'
  ```

  ```bash CLI
  shade instances delete <instance-id>
  ```
</CodeGroup>
