With the `docker` [launch configuration](/getting-started/concepts#launch-configuration) you can spin up a GPU VM and start a container on it in one API call. A good first workload is running evals on a new model from Hugging Face.

Shadeform publishes [`shadeform/lm-eval-harness`](https://hub.docker.com/r/shadeform/lm-eval-harness), an image that wraps [lm-eval-harness](https://github.com/EleutherAI/lm-evaluation-harness) with HF Transformers. It is configured entirely through environment variables:

| Variable | Description | Example |
| --- | --- | --- |
| `model` | Hugging Face model id to evaluate | `mistralai/Mistral-7B-Instruct-v0.2` |
| `tasks` | Comma-separated lm-eval tasks | `hellaswag` |
| `num_fewshot` | Number of few-shot examples | `10` |
| `HUGGING_FACE_HUB_TOKEN` | Read token for gated models (Llama, Gemma, Mistral) | `hf_...` |

In this guide we run [Mistral-7B-Instruct-v0.2](https://huggingface.co/mistralai/Mistral-7B-Instruct-v0.2) through the Hellaswag benchmark on an A6000.

<Prerequisites />

### Find an available A6000

An A6000 has plenty of memory for a 7B model in fp16 and is one of the most affordable GPUs on the platform. List the ones available right now, sorted by price, and pick the cheapest `cloud` / `region` pair. See [Find the Most Affordable GPUs](/guides/mostaffordablegpus) for more ways to filter.

<CodeGroup>
  ```bash curl
  curl --request GET \
  --url 'https://api.shadeform.ai/v1/instances/types?shade_instance_type=A6000&available=true&sort=price' \
  --header 'X-API-KEY: <api-key>'
  ```

  ```bash CLI
  shade instances list-types --shade-instance-type A6000 --available --sort price
  ```
</CodeGroup>

### Launch the benchmark

Create the instance with the `shadeform/lm-eval-harness` image and the variables above. The container downloads the model, runs the benchmark and prints the results to its logs.

<CodeGroup>
  ```bash curl
  curl --request POST \
  --url 'https://api.shadeform.ai/v1/instances/create' \
  --header 'X-API-KEY: <api-key>' \
  --header 'Content-Type: application/json' \
  --data '{
    "cloud": "massedcompute",
    "region": "us-central-2",
    "shade_instance_type": "A6000",
    "shade_cloud": true,
    "name": "lm-eval-mistral",
    "launch_configuration": {
      "type": "docker",
      "docker_configuration": {
        "image": "shadeform/lm-eval-harness",
        "envs": [
          { "name": "model", "value": "mistralai/Mistral-7B-Instruct-v0.2" },
          { "name": "tasks", "value": "hellaswag" },
          { "name": "num_fewshot", "value": "10" },
          { "name": "HUGGING_FACE_HUB_TOKEN", "value": "<hugging-face-token>" }
        ]
      }
    }
  }'
  ```

  ```bash CLI
  shade instances create \
    --cloud massedcompute \
    --region us-central-2 \
    --shade-instance-type A6000 \
    --shade-cloud=true \
    --name lm-eval-mistral \
    --launch-configuration '{
      "type": "docker",
      "docker_configuration": {
        "image": "shadeform/lm-eval-harness",
        "envs": [
          { "name": "model", "value": "mistralai/Mistral-7B-Instruct-v0.2" },
          { "name": "tasks", "value": "hellaswag" },
          { "name": "num_fewshot", "value": "10" },
          { "name": "HUGGING_FACE_HUB_TOKEN", "value": "<hugging-face-token>" }
        ]
      }
    }'
  ```
</CodeGroup>

```json Response
{
  "id": "d290f1ee-6c54-4b01-90e6-d701748f0851"
}
```

### Check the results in the console

Open the instance under [Running Instances](https://platform.shadeform.ai/instances) and switch to the **Logs** tab to stream the container output. When the run finishes it looks like this:

![FinishedBenchmark](/images/finishedbenchmark.png)

Here Mistral-7B-Instruct-v0.2 reaches a normalized accuracy of 84.6% with 10 few-shot examples on Hellaswag.

### Check the results from your terminal

Poll the instance until `status` is `active` and take note of the `ip`.

<CodeGroup>
  ```bash curl
  curl --request GET \
  --url 'https://api.shadeform.ai/v1/instances/<instance-id>/info' \
  --header 'X-API-KEY: <api-key>'
  ```

  ```bash CLI
  shade instances get <instance-id>
  ```
</CodeGroup>

SSH in with the instance's private key and read the container logs. The `-a` flag on `docker ps` lists the container even after it has exited.

```bash
ssh -i <path-to-private-key> shadeform@<instance-ip>
docker ps -a
docker container logs <container-id>
```

### Clean up

The container exits when the benchmark is done, but the VM keeps running and billing until you delete it.

<CodeGroup>
  ```bash curl
  curl --request POST \
  --url 'https://api.shadeform.ai/v1/instances/<instance-id>/delete' \
  --header 'X-API-KEY: <api-key>'
  ```

  ```bash CLI
  shade instances delete <instance-id>
  ```
</CodeGroup>

<Tip>
  Set `auto_delete` on the create request to a spend or time threshold and Shadeform will tear the instance down for you. See the [Create Instance API Reference](/api-reference/instances/instances-create).
</Tip>
