This guide walks through launching, accessing and deleting a GPU instance from the [Shadeform console](https://platform.shadeform.ai). If you would rather work from code, jump to the [API](/interfaces/api), [CLI](/interfaces/cli) or [MCP server](/interfaces/mcp) pages; they all drive the same account.

### 1. Create an account

Go to [shadeform.ai](https://shadeform.ai) and click "Sign up for free". After signing up you will be asked for your name and organization details.

### 2. Find the right GPU

Open the Marketplace to see every GPU instance you can launch. The dropdowns in the top right filter by GPU type, number of GPUs per instance and interconnect. Each row shows the provider, region, hourly price and whether capacity is available right now.

![GPU Filters](/images/platform-filter.png)

### 3. Launch your instance

Click "Launch" on the instance you want to open the launch sidebar. There you can review the hardware, choose an operating system image, pick an SSH key, optionally add a startup script or container, name the instance and confirm.

### 4. Add funds to your wallet

The first time you launch, you will be prompted to fund your Shadeform Wallet, shown in the top right corner. Payment is handled through Stripe. You can also enable Auto Top Up so your card is charged automatically when the balance drops below a threshold you set.

### 5. Access your instance

Once the wallet is funded, the instance starts provisioning. Track it on the "Running Instances" page; depending on the provider it can stay in a pending state for up to 10 minutes. When it reaches "Active", click the instance to open its details and copy the SSH command.

If you launched with the default Shadeform-managed key, download the private key with the "Download Private Key" button on the same page, restrict its permissions, then connect:

```bash
chmod 600 private_key.pem
ssh -i private_key.pem shadeform@<ip>
```

![Access machine](/images/running.png)

<Note>
  Having trouble connecting? See [Common SSH Issues](/guides/sshissues).
</Note>

### 6. Delete your instance

Billing runs per second while the instance exists, including while it is idle. Delete it from the "Running Instances" page when you are done.
