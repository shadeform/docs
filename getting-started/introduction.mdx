Shadeform is a cloud GPU marketplace. It gives you a single place to compare availability, pricing and specs for GPU instances across 15+ cloud providers, and to launch and manage those instances without creating an account with each provider or juggling their billing.

Every instance you launch is a plain virtual machine you can SSH into, optionally with a startup script or container that runs as soon as it is ready, and persistent volumes attached.

## Choose how you want to work

All four interfaces operate on the same account and the same instances; use whichever fits the task.
